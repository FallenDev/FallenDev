## Software & Systems Engineer

I design and build high-performance software with a focus on **server-authoritative multiplayer systems, distributed architecture, concurrency, networking, and data-oriented simulation**.

I'm currently developing **Zolian - Age of Ruin**, a server-authoritative MMORPG built around Unity's **ECS/DOTS** architecture. Much of my work centers on scalable world simulation, server infrastructure, persistence, networking, and extracting as much deterministic performance as possible from C# systems.

## Zolian - Age of Ruin

**Zolian - Age of Ruin** is my current long-term engineering (passion) project: a modern MMORPG designed around a server-authoritative, data-oriented architecture.

The project is an ongoing exploration of the engineering problems that make persistent multiplayer worlds interesting to build:

* Large-scale authoritative simulation
* ECS/DOTS-based world processing
* World layering and horizontal scalability
* High-concurrency server workloads
* Multiplayer networking and replication
* SQL-backed persistence
* Server lifecycle and infrastructure
* Observability and production performance
* Deterministic, allocation-conscious systems design

The current game and infrastructure are being developed privately while the architecture continues to evolve.
